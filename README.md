Visualisation de l’Incertitude des Données sur la Malaria avec Tableau

Ce projet présente une analyse visuelle des données de la malaria en utilisant Tableau,après avoir nettoyé le dataset pris kagggle avec python j'ai fait un focus particulier sur :

L’incertitude des estimations

La fiabilité des données

L’évolution des cas par pays et par année

L’objectif est d’aider à mieux comprendre non seulement les chiffres bruts, mais aussi la qualité des estimations, ce qui est essentiel dans le domaine de la santé publique.
